# AISky 0.9.8

这一版集中修复深色地图可读性、最大化后的地图比例，以及长时间使用时的内存与拖动流畅度。

## 深色地图

- 有预报填色时，海岸线、国界、省界和地名改用深色地图墨线，不再被大片白线覆盖
- 河流与湖泊保留清晰的蓝色层次，更容易和行政边界区分
- 没有预报图层时自动切换为适合深色底图的柔和青色线条，避免地图轮廓消失

## 等比例地图

- 横向与纵向统一使用同一个“每像素经纬度尺度”
- 普通窗口、最大化、恢复窗口和滚轮缩放之间不再出现横向拉伸
- 全球视图使用无留白裁切，并保留东西方向循环拖动

## 流畅度与内存

- 主地图与风场画布加入像素预算，高分屏和超宽屏不再盲目扩展到双倍全尺寸
- 拖动开始和结束时不再反复销毁、重建大画布
- 拖动过程中暂时简化河湖、省界和地名绘制，松手后立即恢复完整地图
- 风粒子轨迹改为低分配绘制，减少每帧临时数组与垃圾回收抖动
- 栅格与格点序列缓存改为 LRU，并在淘汰时主动释放纹理画布
