# AISky 0.9.9

这一版更新全球国界数据，并重点改善中国区域边界的准确度和缩放层次。

## 全球国界

- 全球国界改用 MeteoInfo `country.shp`，从 249 个国家面中提取共享边界
- 将碎片化边界合并、保形简化为 330 条连续线，在保留轮廓的同时控制绘制开销
- 海岸线、河流、湖泊、城市和中国省界继续使用 AISky 原有资源，避免引入无关地图文件

## 中国精细边界

- 中国区域使用 MeteoInfo `cn_border.shp` 的 78 条精细陆地边界
- 海岸和岛屿采用分级显示：区域尺度保持清爽，继续放大后自动补充小岛细节
- 移除旧全球数据中与中国相邻的重复边界，避免双线和局部加黑

## 绘制与维护

- 全球边界改为批量 Canvas 路径绘制，减少每帧描边调用
- 仅分发 AISky 所需的简化坐标，不包含原始 Shapefile 属性表和无关栅格
- 新增地图来源说明、可重复生成脚本和边界范围自动测试
