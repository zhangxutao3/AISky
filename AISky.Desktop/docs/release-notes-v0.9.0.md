# AISky 0.9.0

本地双模型台风路径与中国台风警戒线。

## 台风路径

- 从 AISky-Energy、AISky-SDS 本地预报的 SLP 与 WIND10 场自动识别热带气旋路径
- 只展示起报后未来 72 小时，并按热带风暴及以上强度筛选模拟路径
- 分析在 Web Worker 中运行，切换时次和图层时不阻塞地图交互
- 使用穿过模式中心点的平滑样条曲线，消除低分辨率网格造成的阶梯感
- Energy 使用珊瑚色实线，SDS 使用青色虚线
- 路径节点按中央气象台六级热带气旋强度标准分色
- 缩放时自适应减少或增加路径节点，兼顾全球视图清晰度与局地细节

## 交互与信息

- 鼠标悬停路径点可快速查看模型、有效时间、强度、风速和气压
- 单击路径点打开详情卡，展示起报、预报时效、经纬度和识别置信度
- 台风时间跟随 AISky 的 UTC / 自定义显示时区
- 右侧增加独立“模型模拟台风路径”开关，并记忆用户选择
- 明确标注路径为模式场自动识别结果，不冒充官方实况或官方预报

## 警戒线

- 增加中国地区 24 小时台风警戒线（黄色实线）
- 增加中国地区 48 小时台风警戒线（黄色虚线）
- 警戒线使用国家气象中心台风网当前公开页面中的坐标

## 稳定性

- 缺少某一模型或某一变量时只跳过对应模型，不显示残留路径
- 同一输入使用会话缓存，重复开关和切换图层无需重新读取
- 台风开关设置兼容旧版配置，升级后默认启用
