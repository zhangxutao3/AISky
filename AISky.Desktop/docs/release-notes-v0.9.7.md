# AISky 0.9.7

这一版重点让新用户更快看懂 AISky，并改善从托盘返回应用时的启动衔接。

## 图形化新手教程

- 新增 6 页简明教程，覆盖预报选择、地图与序列、变量与色带、风场与台风、后台同步以及显示设置
- 每页加入与真实界面对应的轻量示意图，比纯文字更直观
- 教程支持上一步、下一步和短促滑入动画，并自动适配明亮与深色界面
- 默认在进入应用后打开；勾选“不再自动弹出”后停止自动提示
- 可随时从左上角“…”菜单中的“新手教程”重新打开，并可重新开启自动提示

## 托盘恢复体验

- 从托盘恢复前预先准备封面，避免封面和正式界面同时闪现
- 适当延长封面停留并统一淡出、缩放节奏，使恢复过程更容易感知但不过分拖延
- 地图尚未准备完成时继续保留封面，避免提前露出空白或加载中的地图
- 托盘恢复完成后再按用户设置显示教程或更新提示
