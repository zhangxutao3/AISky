# AISky 0.6.0

首个可分发的 AISky Windows 桌面预览版。

## 新功能

- 本地 NetCDF 预报产品解析、索引与可视化
- 气象图层、图例、格点取值和预报时间轴
- AISky-Energy / AISky-SDS 数据导入与后台同步
- 通知区运行、开机启动与缓存保留设置
- GitHub Release 更新检查、下载校验和独立更新助手

## 界面与体验

- 沉浸式全球气象地图与 Fluent 浮层控制
- 明暗主题、原生设置页和软件更新中心
- 发布包内置 .NET 与 Windows App SDK 运行时

应用数据、缓存、设置和日志均保存在 `%LOCALAPPDATA%\AISky\Desktop`，
安装更新不会删除这些用户数据。
