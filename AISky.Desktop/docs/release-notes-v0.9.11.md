# AISky 0.9.11

这一版重点改善地图拖动流畅度，并增强风粒子的视觉辨识度。

## 地图交互性能

- 仅绘制当前视口实际可见的经度世界副本，避免在画布外重复绘制完整地图
- 拖动期间使用已有的主要海岸与岛屿轮廓，松手后立即恢复完整精细地图
- 地图折线改用直接投影，减少高频拖动渲染中的临时数组分配
- 拖动期间暂停格点取值和台风命中检测，松手后完整交互自动恢复
- 3440 × 1440、60° 视野的矢量地图基准中，单帧平均耗时由约 1.70 ms 降至约 0.36 ms

## 风粒子

- 增加粒子密度和轨迹线宽
- 提高轨迹中段与头部的不透明度，并保留从有色到透明的自然渐隐
- 使用更清晰的浅青色尾迹，让浅色和复杂填色背景上的风场更易辨认

## 色带目录

- 补充 Batlow 与 Roma 两套连续色带，保持色带完整性测试标准

## 发布流程

- 新增可复用的个人 `github-api-release` Skill，用 GitHub API 同步提交并发布、回读校验 Release 附件
