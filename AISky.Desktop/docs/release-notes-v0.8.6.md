# AISky 0.8.6

启动、数据存储与后台状态体验升级。

## 启动与安装

- 播放按钮改为内置矢量图标，不再依赖系统字体字形
- 每次冷启动先显示 AISky 封面，地图和本地数据就绪后再进入主界面
- 无完整预报数据时自动进入初始化下载界面，不读取旧版本残留缓存
- 主程序、开始菜单和桌面快捷方式显式使用 AISky 图标
- 软件更新安装完成后继续由独立更新助手自动重新启动 AISky

## 数据存储

- 默认数据目录改为软件目录下的 `AISkyData`
- 设置中可选择新的数据文件夹
- 切换目录时复制全部 AISky 数据、保存新位置并自动重新启动
- 新实例确认迁移成功后安全移除旧数据目录
- 目标目录必须为空，避免混入旧缓存

## 同步与状态

- Energy 与 SDS 使用两个独立 Python 工作进程并行同步
- 右上角约每 3.5 秒垂直轮播每个模型的检查、下载、完成或失败状态
- 下载期间显示每个模型的实时传输速度
- SQLite 并行写入等待时间增加到 30 秒
- 每 6 小时在后台检查一次 GitHub Release；发现新版本时在界面提醒

## 地图动画

- 风粒子寿命与尾迹长度约缩短 50%，画面更利落
