# AISky 0.8.1

首次启动与超宽屏显示修复。

## 首次数据准备

- 新增明确的首次设置完成标记，不再因为电脑上残留旧版缓存而跳过密码界面
- 首次界面可以选择 `AISky-Energy` 或 `AISky-SDS`
- 输入密码后只准备所选模型的最新起报
- 必须完整获得 +3h 至 +360h 共 120 个连续预报时次，全部校验成功后才进入地图
- 下载不完整时停留在准备界面，并显示当前时次数；重试时跳过已有文件
- 密码仅在完整序列准备成功后保存

## 显示与稳定性

- 地图首次最大化时根据 WebView 实际宽高比扩展经纬度视野，修复带鱼屏横向拉伸
- 修复主窗口与页面同时初始化时可能争用 `settings.json.tmp` 的首次启动错误
- 设置写入改用串行化和独立临时文件，降低异常退出造成配置损坏的风险

## 开发与发布

- 新增约 2 秒完成的 `Test-AISky.ps1 -Quick` 数据冒烟测试
- 发布脚本支持复用已验证的完整 Python 运行时，减少补丁打包等待时间
