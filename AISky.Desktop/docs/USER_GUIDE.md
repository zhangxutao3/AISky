# AISky 用户使用说明

## 1. 安装与启动

1. 下载 `AISky-Setup-win-x64.exe` 并双击运行。
2. 安装器默认安装到当前用户目录，不需要管理员权限。
3. 保留“创建桌面快捷方式”后，可从桌面或开始菜单启动 AISky。

发布包已包含 .NET、Windows App SDK 和 Python 数据运行时，不需要另外安装开发工具。
AISky 的起报和预报时间全部使用 UTC 世界时。

需要免安装使用时，可以下载 `AISky-Desktop-win-x64.zip`，完整解压到可写目录后运行
`AISky.Desktop.exe`；不要直接从压缩包预览窗口启动。

## 2. 第一次打开

每次从完全退出状态启动 AISky，都会先显示品牌封面；程序会在封面后完成数据索引和
地图准备，不把尚未加载的空地图展示给用户。若当前数据目录没有一组完整预报，封面会
继续显示初始化下载界面；旧位置的零散缓存不会自动混入：

1. 选择首次加载的预报模型。
2. 公开数据可以把密码留空；服务器明确要求验证时再填写访问密码。
3. 点击“开始初始化并进入”。封面会显示总进度、当前时次数和单文件传输量。
4. 软件从最近的固定起报时刻开始，最多向前探测 3 天。
5. 同一起报的 +3h 至 +360h 共 120 个文件全部下载、校验和解析成功后，
   软件才进入地图。
6. 已有 `.nc` 文件时，也可以点击“导入本地 NetCDF”加入本地缓存；首次设置
   仍需具备一组完整的 120 时次序列。

网络不可用、密码错误或文件损坏时，页面会说明原因。修正后可直接重试，不完整的
`.part` 文件不会加入本地索引。

## 3. 查看预报

- 顶部选择模型、起报时间和预报时间。
- 右侧“预报图层”切换气温、风速、降水、气压、云量等产品。
- 鼠标滚轮缩放地图，按住鼠标拖动平移；移动指针可快速查看经纬度和格点值。
- 单击地图中的任意有效格点，左侧会滑出详情抽屉，显示完整栅格值以及当前起报的
  多时次预报曲线。点击抽屉右上角关闭按钮或按 `Esc` 可关闭。
- 底部时间轴切换预报时次，播放按钮可循环播放。
- 地图获得键盘焦点后，可按 `←` / `→` 切换前后时次，按空格播放或暂停，按
  `Home` 恢复全球视图。
- 所有下拉框和时间轴只显示本地已经下载并通过校验的数据。

## 4. 台风路径

- 打开右侧“模型模拟台风路径”开关后，地图会分析本机已有的 AISky-Energy 和
  AISky-SDS 预报，不访问外部台风数据源。
- 每次只展示起报后未来 72 小时，避免较长时效的不确定路径干扰画面。
- 路径基于海平面气压和 10 米风场自动识别。Energy 使用珊瑚色实线，
  SDS 使用青色虚线；节点颜色表示热带低压至超强台风的强度等级。
- 鼠标悬停可快速查看路径点，单击节点可查看所属模型、起报时间、有效时间、
  预报时效、中心气压、最大风速、强度和识别置信度。有效时间会跟随软件的
  UTC / 自定义时区设置。
- 黄色实线和虚线分别为中国地区 24 小时、48 小时台风警戒线。
- 热带气旋等级以近中心最大风速判定，不使用单一中心气压门槛；气压只参与识别
  闭合低压和置信度。这些路径不是气象部门发布的实况或官方预报路径，
  不应单独作为防灾决策依据。

## 5. 下载历史数据

点击左上角下载按钮，打开“回溯下载预报数据”：

1. 选择模型、开始日期/固定时刻和截止日期/固定时刻。
2. 如果数据链接要求验证，输入访问密码；公开数据可以留空。
3. 点击“开始后台下载”，对话框随即关闭，可继续使用地图。

已有且校验通过的文件会自动跳过。右上角会在任务运行时显示进度和取消按钮；
小窗口也可以从“更多 → 取消回溯下载”取消。取消后已完成文件保留，未完成文件不入库。
失败项会计数并保留记录，再次提交同一范围即可重试。
当前分享页采用 POST 下载，服务器不保证字节级断点续传；AISky 会重新下载未完成文件。

## 6. 自动同步与后台运行

- 点击顶部自动同步按钮开启或暂停；状态会保存，下次启动继续使用。
- 从关闭切换为开启时会立即检查 Energy 与 SDS：近期完整模型自动跳过，缺失或
  陈旧模型同步最近可用起报的 120 个时次；之后默认每 3 小时再次检查。
- Energy 与 SDS 使用两个独立数据进程并行同步；一个模型失败不会中断另一个模型。
- 右上角在同步期间像信息牌一样轮播每个模型的状态、进度和实时下载速度；完成后
  恢复为各模型状态。所有显示时间都跟随“更多 → 显示时区”的选择。
- 点击“更多 → 立即同步最新数据”可随时手动检查。
- 默认点击窗口关闭按钮会隐藏到 Windows 通知区，后台同步和缓存维护继续运行。
- 双击通知区 AISky 图标重新打开。右键菜单可立即同步、切换自动同步、检查更新或退出。

如需点击关闭按钮后直接退出，在“更多 → 设置”中关闭“关闭主窗口后继续运行”。

## 7. 设置、缓存与日志

“更多 → 设置”可以调整：

- 气象图层透明度、经纬网和城市标注。
- 自动同步开关和每次同步的未来预报小时数。
- 数据存储目录。选择新的空文件夹后，AISky 会复制原始预报、索引、缓存、日志和设置，
  自动重启，再清理受控的旧目录。
- 缓存保留 3 / 7 / 15 / 30 天或自定义天数。
- 登录 Windows 后在通知区启动。
- 每 6 小时在后台静默检查软件更新。
- 安全清理已经过期的本地缓存。

默认用户数据保存在程序目录的 `AISkyData` 中：

```text
<AISky 程序目录>\AISkyData\data    原始 NetCDF
<AISky 程序目录>\AISkyData\cache   SQLite 索引与地图缓存
<AISky 程序目录>\AISkyData\logs    运行日志
<AISky 程序目录>\AISkyData\config  用户设置
```

设置页会显示实际位置。软件升级不会删除当前数据目录；便携版请完整解压到具有写入
权限的位置。

## 8. 软件更新

点击“更多 → 检查软件更新”。发现新版本时可查看版本号、UTC 发布时间、更新说明和
下载大小。即使没有手动打开菜单，AISky 也会每 6 小时在后台检查一次；只有发现新版本
时才弹出提示。AISky 下载后会校验大小与 SHA-256：安装版静默升级并重新启动，便携版由
独立更新助手替换程序，均不需要用户再次下载或手动解压。

## 9. 常见问题

**提示访问验证失败**

公开数据先尝试清空密码重试；服务器明确要求验证时再输入正确密码。密码只保存在本机
设置中。

**提示网络不可用或下载失败**  
检查网络，稍后点击重试。自动同步开启时也会在下个周期重试。

**提示 NetCDF 文件损坏**  
删除来源不明的文件并重新下载，或导入一份完整文件。AISky 不会把损坏文件用于绘图。

**地图没有更新**  
点击左上角刷新按钮。确认模型、起报时间和预报时间下拉框中已有本地数据。

**关闭窗口后找不到软件**  
AISky 默认仍在通知区运行。双击图标恢复，右键图标选择“退出 AISky”才会彻底退出。
