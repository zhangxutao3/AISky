# AISky 本地模式台风路径（0.9.0 已实现）

## 目标

在现有“风场流线”区域增加“模型模拟台风路径”开关，显示：

1. AISky-Energy / AISky-SDS 从本地模式场识别出的路径；
2. 中国地区 24 小时和 48 小时台风警戒线；
3. 所有时间按 UTC 保存，显示时统一跟随 AISky 的时区选择。

## 模式路径

模式路径不依赖外部台风网页。Web Worker 从每个预报时次的 SLP、10 米风场中：

- 在热带海域寻找闭合低压中心；
- 结合近中心风速、气压梯度和前一时次位置排除普通低压；
- 以最大移动距离约束连接连续中心；
- 输出经纬度、中心气压、最大近地面风速、预报时效和置信等级。

0.9.0 以 SLP + WIND10 为核心，显示“模式识别路径”，明确区别于官方台风预报。
识别计算在地图 UI 线程之外执行，并按两种模型独立缓存，不阻塞地图拖动。
每个起报分析并展示未来 5 天（120 小时）。热带气旋强度按中心附近最大风速划分，
中心气压只用于闭合低压筛选，不设置人为的“台风气压线”。

## 0.9.0 范围

- 中央气象台台风网提供实时台风展示，但当前未找到面向第三方应用、具有稳定版本承诺的正式公开 API 文档。
- 国家气象中心英文台风页面提供台风路径与强度产品入口，但页面同时声明站点资料的下载与再发布受授权限制。
- 日本气象厅提供公开的防灾信息 XML PULL 数据，包含北西太平洋台风位置和预报信息，可作为技术备用源，但界面必须标注为 JMA，不能显示为“中央气象台”。

按照产品范围，0.9.0 只显示两个本地模型，不接入任何官方路径或第三方实时接口。
界面明确标注结果来自本地 SLP 与 WIND10 模式场。

## 数据与缓存

- 分析输入仅为当前数据目录中两个模型最近起报的 SLP / WIND10 地图抽样缓存。
- 同一批输入的结果在地图会话内缓存，切换图层或时次不会重复分析。
- 没有某模型的完整输入时不生成该模型路径，也不复用另一模型或旧起报的结果。

## 地图交互

- “风场流线”下增加“模型模拟台风路径”开关。
- Energy 使用珊瑚色实线，SDS 使用青色虚线。
- 路径点点击后显示 UTC/当前时区时间、中心气压、最大风速、来源和预报时效。
- 路径点按热带低压、热带风暴、强热带风暴、台风、强台风、超强台风分色。
- 模式中心先用五点低通滤波消除网格跳跃，再使用样条曲线绘制；原始中心数据
  仍用于详情数值。
- 当前模型路径位于最上层并保持模型色，另一个模型以灰色弱化。
- 路径点悬停显示三小时时效与脉冲预选，单击后切换整个软件的模型、起报和时刻。
- 地图缩小时减少节点密度，放大后显示更多路径点。
- 24 小时警戒线使用黄色实线，48 小时警戒线使用黄色虚线。

## 验证

- 纯算法使用合成移动涡旋做自动化单元测试；
- 使用本机 Energy / SDS 各 120 时次数据做真实输入回归；
- 桌面端检查开关、路径渲染、悬停、点击详情、缩放节点密度和时区转换。
