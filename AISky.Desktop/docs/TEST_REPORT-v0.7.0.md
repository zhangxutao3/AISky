# AISky 0.7.0 第七阶段测试报告

测试环境：Windows x64、Release 构建、独立空数据目录、内置/系统 Python 3.11 数据
管线。测试数据为脚本生成的小型 NetCDF，不包含业务预报数据。

| 项目 | 结果 | 验证方式 |
|---|---|---|
| 首次启动 | 通过 | 空目录启动后显示引导页，获得有效时次前不能进入地图 |
| 无网络/数据不存在 | 通过 | 本地模拟服务返回缺失与断连，工作进程安全返回并保留空索引 |
| 下载失败重试 | 通过 | 首次连接中断，第二次自动成功，数据库记录尝试次数 2 |
| 损坏 NetCDF | 通过 | 损坏文件被标为 invalid/error，不进入绘图索引 |
| 损坏 SQLite | 通过 | 原库自动备份为 `.corrupt-*` 并重建通过完整性检查的新库 |
| 回溯下载 | 通过 | 本地分享服务完成范围下载、去重、解析和索引刷新 |
| 自动同步 | 通过 | 开关持久化，最新起报同步与清理流程通过 |
| 托盘运行 | 通过 | 关闭主窗口后进程保持响应、主窗口句柄隐藏、后台空闲 CPU 为 0 |
| 软件更新 | 通过 | GitHub Release 返回当前版本、说明、UTC 发布时间和下载大小 |
| 首次导入 | 通过 | 从引导页导入有效 NetCDF 后进入地图，生成 8 个图层 |
| Release 编译 | 通过 | x64 Release 构建 0 错误、0 警告 |
| 响应式界面 | 通过 | 首次启动卡片在紧凑/中等/宽窗口切换尺寸，低高度图层面板可滚动 |

数据管线一键测试：

```powershell
.\scripts\Test-AISky.ps1
```

脚本会临时生成 NetCDF，依次执行基础下载、第五阶段同步清理和第七阶段容错测试，结束后
删除临时数据。发布包测试还会在系统 Python 不参与的环境下调用包内
`Python\python.exe` 完成状态检查和 NetCDF 导入。
