# AISky 0.8.0

第八阶段地图交互、长时间序列和视觉体验更新。

## 时间序列

- 支持未来 15 天共 120 个预报时次，并按每 8 个时次一组显示
- 点击时间格即可定位预报时刻，播放时自动跟随当前时间格
- 地图获得焦点后，可使用左右方向键切换时次、空格播放或暂停
- 格点详情从左侧滑出，显示当前值和同一起报的 120 时次变化曲线

## 地图与图层

- 新增国家边界、中国省界、河流、湖泊和随缩放调整密度的城市标注
- 全球视图支持东西方向循环拖动，并修复边界拖动后的地图变形
- 风场流线更清晰、更密集，仍可随时关闭
- 变量面板新增关键词搜索和分类筛选，变量缩略图直接展示产品填色
- 支持 UTC 以及用户选择的固定时区显示

## 界面与性能

- 重新整理顶部选择器、右侧图层栏、色标、经纬度卡片和底部时间轴的对齐关系
- 优化最大化与中等窗口布局，减少面板重叠和无效空白
- 时间切换复用完整序列描述并预取下一帧，减少重复数据传输
- 播放时只更新前后两个时间格，格点曲线只移动当前时次指示点
- 保持单实例运行，再次打开程序会恢复已有 AISky 窗口
