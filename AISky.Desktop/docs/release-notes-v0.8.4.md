# AISky 0.8.4

双模型自动同步、时区状态显示与后台回溯下载修复。

## 自动同步

- 从关闭切换为开启时，立即检查 AISky-Energy 与 AISky-SDS
- 已有近期完整 120 时次预报的模型自动跳过，避免重复下载
- 缺失或陈旧模型同步最近可用起报；过期残留会按缓存保留策略清理
- 用户明确选择无数据模型时，起报和预报选择保持空白，不再显示其他模型的时间
- 右上角在同步期间显示当前模型和进度，任务结束后自动隐藏进度条
- 下次检查时间统一按当前显示时区格式化，切换 UTC+8 后立即刷新

## 回溯下载

- 提交回溯范围后转入后台运行，对话框立即关闭，地图可继续操作
- 右上角显示回溯进度和取消按钮；小窗口可从“更多”菜单取消
- 取消后保留已经完成并校验通过的文件，未完成文件不会进入索引

## 稳定性

- 修复 WinUI 控件初始化事件在设置载入前回写默认值的问题
- 首次初始化规则保持不变：Energy 或 SDS 任意一个模型具备完整 120 时次即可进入主界面
