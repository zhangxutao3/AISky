# AISky 0.9.6

这是一次围绕流畅度、视觉密度和气象变量规范的综合调优。

## 更轻快的地图

- 拖动和滚轮缩放期间使用轻量渲染帧，结束交互后自动恢复高清画质
- 保持经纬方向等比例缩放，全球视图继续支持东西方向循环拖动
- 修复 180°附近的栅格拼接白缝
- 风场流线略微加粗，保留速度差异与渐隐轨迹
- 经纬度标签加深并增加浅色描边，避开顶部和底部仪表

## 更紧凑的界面

- 压缩顶部命令、模型选择和右侧变量列表的留白
- 统一主要浮动卡片高度、边距和圆角，改善中小窗口避让
- 变量列表默认按英文标识字母顺序排列
- 右上角同步卡片可点击展开 Energy、SDS 的独立状态、进度和速度；点击外部自动收起

## 变量范围与单位

- 按 AISky-Energy 与 AISky-SDS 产品表统一显示范围、单位和换算
- 温度统一为摄氏度，气压统一为 hPa
- 比湿显示为 kg/kg，沙尘质量与沉降量按参考单位换算
- 无量纲变量统一显示单位“无”
- 已有缓存无需重新下载，显示层会兼容转换旧版缓存数值

## 启动体验

- 启动封面支持明亮与深色主题
- 从托盘恢复窗口时加入短促的淡出与轻微缩放动画
- 封面只覆盖恢复过程，不重新加载地图和预报数据
