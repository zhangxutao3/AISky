# AISky 0.7.0

第七阶段稳定性与首次使用体验更新。

## 新功能

- 无本地数据时显示首次启动引导，自动回退寻找最近 3 天可用起报
- 有效预报下载或导入成功后才进入主地图
- 发布包内置 Python、NumPy、netCDF4 和 requests，普通用户无需安装 Python
- 新增可重复运行的一键数据管线与容错测试

## 稳定性

- 下载连接中断最多自动重试 3 次
- 密码错误、缺失数据和损坏 NetCDF 使用友好的中文说明
- 损坏 SQLite 自动备份并重建，避免应用无法启动
- Release 构建保留 JSON 运行时元数据，修复干净环境初始化失败

## 界面与性能

- 首次启动页延续 AISky 气象可视化风格并适配多种窗口宽度
- 低高度窗口中的图层面板不再与底部时间轴重叠
- 后台驻留时保持空闲，不持续占用 CPU
