# AISky 0.9.2

台风路径交互和深色主题修复。

## 台风图层

- 路径节点以对应模型色为主色，中心小点保留中文强度提示
- 当前选择模型的路径始终绘制在最上层
- 非当前模型路径自动变灰，减少重叠时的辨识干扰
- 当前预报时刻只在当前模型路径上高亮

## 时刻交互

- 鼠标靠近路径时自动吸附到最近的三小时时次
- 悬停卡直接显示 `+N 小时`、有效时间、模型、气压和最大风速
- 增加轻量脉冲预选动画，点击前即可确认目标位置
- 单击路径点后同步切换模型、起报、预报时刻、时间轴和地图图层
- 格点序列曲线支持悬停预览 `+N 小时`、有效时间和值
- 单击格点曲线可同步跳转顶部预报选择、主地图与底部时间轴

## 深色主题

- 左侧格点序列抽屉、当前读数、坐标框和曲线背景完整适配深色主题
- 深色主题使用更清晰的曲线、面积渐变、网格与当前时刻标记

## 风场动画

- 弱风粒子使用稍长的连续轨迹，便于辨认流向
- 强风粒子保持更快移动速度，但自动缩短并略微收细轨迹，减少台风核心视觉堆积
